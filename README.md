

# CompTIA Security+ (SY0-701) | Practical Labs

A portfolio of selected hands-on cybersecurity labs completed as part of my CompTIA Security+ (SY0-701) training.

These exercises demonstrate practical experience with security architecture, vulnerability management, identity and access management, log investigation, and basic security operations automation across Windows and Linux environments.

Each documented lab includes practical implementation, supporting evidence, technical observations and key learning outcomes.

## Portfolio Approach

Each project focuses on:

1. **Objective** — The purpose of the practical exercise.
2. **Implementation** — The tools, commands and configurations used.
3. **Evidence** — Selected screenshots, scripts and results.
4. **Analysis** — What the observed results demonstrate.
5. **Lessons Learned** — Relevant security concepts and potential improvements.

The goal is to demonstrate practical understanding rather than simply reproduce course instructions.
